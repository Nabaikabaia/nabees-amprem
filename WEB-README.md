# Nabees Alight Motion Generator

A Three.js visual frontend added alongside the original RynAmPrem CLI.

## Important
The existing `index.js` and `lib/auth.js` connection layer is preserved. The website is a static visual/control layer and does **not** move Firebase credentials, refresh tokens, or authentication requests into a browser proxy.

Open `web/index.html` in a modern browser or serve the `web/` directory with any static host.

The original CLI remains:

```bash
npm install
npm start
```
